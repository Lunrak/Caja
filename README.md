# Caja - POS para Android 7

Aplicación de punto de venta y control de inventario optimizada para tablets con Android 7 (API 24).

## Stack Tecnológico

- **Framework:** React Native con Expo (SDK 56).
- **Lenguaje:** TypeScript
- **Navegación:** Expo Router.
- **Almacenamiento Local:** SQLite.

## Características (Features)

1. **Dashboard de Reportes:** Ganancias, ventas, inventario y productos.
2. **Gestión de Ventas:** Carrito de compras, cobro y historial.
3. **Inventario:** Alta de productos (con foto/cámara), precios y stock.
4. **Clientes/Proveedores:** Directorio con datos de contacto.

## Notas sobre Android 7

Este proyecto prioriza la compatibilidad con API 24. Se evitarán módulos nativos que requieran APIs superiores a Android 7.0.
